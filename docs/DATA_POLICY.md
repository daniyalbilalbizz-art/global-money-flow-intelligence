# Data Integrity Policy

## Evidence classes
- **Reported:** directly published by an identified source.
- **Estimated:** calculated from disclosed inputs using a documented method.
- **Inferred:** an interpretation or hypothesis; never label it as observed capital flow.

## Required provenance
Each observation should retain source and URL, units, observation time, publication time when available, retrieval time, frequency, transformation/method, and quality status. Missing metadata must be identified, not invented.

## Interpretation controls
- Price appreciation, correlation, market-cap changes, and dominance changes do not independently prove capital moved between assets.
- Do not combine incompatible units or timestamps without explicit transformations.
- Display stale, missing, delayed, and failed feeds distinctly.
- Never commit API keys, credentials, or private user data.
